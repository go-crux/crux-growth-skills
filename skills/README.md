# Skills

Each subdirectory here is one skill: a folder with a `SKILL.md` in it, plus any
reference files that skill reads only when it needs them.

- `plan-black-friday`: reads last year's Black Friday on the client's Growth Brain, tests this
  year's November and December targets against it, grills whoever runs it to an agreed plan, and
  writes the Black Friday plan as one page with a Last year tab and a Plan tab.

This file is deliberately not a `SKILL.md`, so it does not register as a skill
and does not appear in your skill list.
