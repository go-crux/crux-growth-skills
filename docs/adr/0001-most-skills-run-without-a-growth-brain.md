# Most growth skills run without a Growth Brain; a brain-only skill is the upsell

**Status:** Accepted, 2026-10-21.

The plugin is a lead magnet as much as a client tool, and most people who install it have no Growth Brain. So a skill runs without one wherever its craft holds on what the user can give it (a page URL, an export, their own answers), and the parts that need the brain drop out with one line saying what the brain would add and pointing at gocrux.io/contact. A skill whose whole method is the brand's own data (Black Friday planning) stays brain-only and stops without one: those skills are the reason to get a brain. A new skill is designed brain-optional first, and goes brain-only only when no useful run is left without the data.
