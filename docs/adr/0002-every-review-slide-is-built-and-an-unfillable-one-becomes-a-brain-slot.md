# Every slide of the Monthly performance review is always built; one the Sources cannot fill becomes a Brain slot

**Status:** Accepted, 2026-10-26.

ADR-0001 has a brain-optional skill drop the parts that need the brain, with one line saying what it would add. The Monthly performance review instead builds every slide on every run, so the deck's shape never changes with the Source: a slide the brain, connectors or exports cannot fill keeps its action title and carries one fixed line naming the data it needs and that a Growth Brain provides it, and the appendix slides (LTV by order category and order type, line items) are brain-only by design. We accept a deck that, without a brain, shows several near-empty slides, because seeing exactly which views are missing is the skill's standing case for a brain, and a fixed shape keeps one month comparable with the next.
