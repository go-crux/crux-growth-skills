# Glossary

The terms `SKILL.md` and `prioritise-layout.md` use beyond the growth system's own, which are in `growth-system-glossary.md`. Each has one meaning.

- **In flight**: a Project at `Prioritised` or `In progress`, or a Task at `In progress`: the cards a WIP limit counts. A Task at `Blocked` or `To review` is not in flight. _Avoid_: active, open.

- **Room**: the number of cards a limit still allows: 4 less the count in flight. Nothing at 0 or below. _Avoid_: capacity, slack.

- **Stale card**: a Project or Task at `In progress` whose page was last edited 14 days or more before today. _Avoid_: dead card, old card.

- **Unexplained block**: a Task at `Blocked` whose `Blocked by` section names no Open question and no Task, or reads `None`. _Avoid_: orphan block.

- **Stranded Task**: a Ready Task whose Project is not at `Prioritised` or `In progress`: it waits on work the board has not chosen. _Avoid_: orphan, floating task.

- **Candidate**: a card the board could pull next: a Project at `Idea`, or a Ready Task whose Project is at `Prioritised` or `In progress`, or that has no Project. A Ready Task whose `Blocked by` names an open Task or an open question is passed over, not a Candidate. _Avoid_: backlog item.

- **Pull**: moving a Candidate into work: a Project to `Prioritised`, a Task to `In progress`. _Avoid_: assign, schedule.

- **Rank**: the order of the Candidates on one board, set by the four rules in step 5, each deciding only what the rule above leaves tied. _Avoid_: score, priority (that is the Project's `Priority`).

- **Over-limit move**: a move after which a limit's count would be more than 4. Proposed only as step 6 sets out, named as such, and made only on the user's yes. _Avoid_: violation, breach (that is a Decision's).

- **Proposal**: the one table of moves step 6 shows. Nothing in it is written until the user says yes. _Avoid_: plan, recommendation.
