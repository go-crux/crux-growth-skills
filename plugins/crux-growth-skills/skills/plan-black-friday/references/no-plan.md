# No plan on the sheet

Open this when `<client>-daily_budget_versus_actuals` is absent from the roster, has no
`all`/`all` row for a month, or holds no plan for the revenue, orders, new orders or spend of
that month.

1. **Propose.** For each month and measure the sheet does not plan, use the last-year level
   (step 2) as the target and label it "Proposed: last year's Lift on this year's Baseline". It
   reads Achievable by construction, so no Pillar gap follows for it alone. Ask nothing yet: the
   question waits for the grill.
2. **Ask in round 4.** Round 4 opens by asking the user's own figure for each Proposed target,
   recommending the proposed one, so they can answer "yes".
3. **Test what they give.** A target the user gives goes through the Target test as it stands,
   labelled "Team's target" in the Source column.
4. A measure the sheet does plan keeps its sheet figure, labelled "Budget sheet".
