# Glossary

The terms `SKILL.md` and `projects-layout.md` use beyond the growth system's own, which are in `growth-system-glossary.md`. Each has one meaning.

- **Source**: a document the user hands over to scope a Project from: a specification, a plan page, a brief, a pasted note. It is read whole, then treated as a loose idea, and it is provenance, never the only carrier of a fact. _Avoid_: input, attachment, spec (one kind of source).

- **Loose idea**: a Project named only in words, with no `ID` or link, matched against the live Projects on the work and not the wording. _Avoid_: request, ticket.

- **Live Project**: a Project at any `Status` but Archived. A Loose idea is matched against these, a Done Project included, so finished work is found before it is scoped twice. _Avoid_: active Project, open Project.

- **Grounded**: a fact that came from a read in this run or from an answer the user gave. Anything else is an Open question, never the nearest plausible value. _Avoid_: assumed, inferred.

- **Surface**: a system the Project touches, with the exact object on it (a draft theme and section, an email flow, a campaign and ad set, a product and variant). Read as it is today. _Avoid_: channel (that is where the work runs, not what it changes), platform.

- **Size signal**: one of the seven tests in the size table of `project-contract.md` that lands in its Too big column. Two or more make the work several Projects. _Avoid_: red flag, smell.

- **Split**: the work found too big for one Project, cut into a sequence of Projects under one Initiative. _Avoid_: breakdown, decomposition.

- **Stub Project**: a Project filed by a Split with all ten sections grounded from the source and the context load, and not interviewed. It stays at its agreed `Status` until `/to-projects` scopes it. _Avoid_: placeholder, skeleton, draft.

- **Fully scoped**: a Project whose ten sections are written from reads and answers, with every unknown an Open question carrying an owner, a date and the work it blocks. After a Split, the first Project in the sequence is fully scoped and the rest stay stubs. _Avoid_: finished, done (that is a `Status`).

- **Sequence**: the order a Split's Projects run in, with the reason for it. Held on the board by which Projects are `Prioritised`, and written in each Project's `Why` as the Projects it needs first. _Avoid_: roadmap, timeline.

- **Open question**: something the reads and answers leave unknown, written on the Project with an owner, a date and the work it blocks. One that blocks no work is dropped or moved into `Scope`. _Avoid_: TBD, assumption, risk.

- **Question**: one thing asked of the user in the interview, alone in its message, with a recommendation and its reason. "Yes" accepts the recommendation and "just write it" accepts every remaining one. _Avoid_: round (that is the Initiatives and Objectives skills' unit of several questions).

- **Frontier**: the questions still open after an answer: a recommendation the user changed, an answer that raises a new question, or a section that still cannot be written from a read or an answer. The interview ends when it is empty. _Avoid_: backlog, parking lot.
