# Glossary

The terms `SKILL.md` and `initiatives-layout.md` use beyond the growth system's own, which are in `growth-system-glossary.md`. Each has one meaning.

- **The quarter**: the quarter this run plans Initiatives for, written `2027 Q1`. The user names it; otherwise it is the quarter the newest Active Objective holds, which is the one `/to-objectives` last agreed. _Avoid_: period, cycle, sprint.

- **The quarter's Objectives**: every Objective at `Status` Active whose `Quarter` holds the quarter. They are the plan this run breaks down. _Avoid_: goals, the plan.

- **Carried Objective**: one of the quarter's Objectives whose `Quarter` also holds an earlier quarter. Its Initiatives from that earlier quarter are reviewed first. _Avoid_: old objective, rollover.

- **Carry review**: step 3, where each Initiative under a Carried Objective, or under an Objective closed last quarter, is Carried, closed as Done, or closed as Dropped, before any new Initiative is drafted. _Avoid_: clean-up, triage.

- **Dropped Initiative**: an Initiative the team stops without finishing. Initiatives has no Dropped status, so it is set to Done and its `Why` gains the line `Dropped <quarter>: <reason>`. _Avoid_: cancelled, archived.

- **Live row**: an Initiative at any `Status` but Done whose `Quarter` holds the quarter. Rows on other quarters are history. _Avoid_: active row, open initiative.

- **Weakest step**: a step of the Growth model whose rate fell furthest in the Comparison, as the quarter's section of the Strategy map names it, at most three. Each Initiative is picked from one. _Avoid_: bottleneck, leak, problem area.

- **Candidate Initiative**: an Initiative idea named under an Objective on the Strategy map, which this run picks up as a draft. _Avoid_: backlog item, idea.

- **Level test**: the check on every line of an Initiative's page body: would a second Project under this Initiative need it? If yes it stays on the Initiative, and if only one Project needs it, it belongs on that Project. _Avoid_: altitude test (that is the Objective's own).

- **Named gap**: a field the reads and the user's answers leave without a source, written down as open and put to the user, never filled with the nearest plausible value. _Avoid_: assumption, TBD.

- **Class**: where a proposed Initiative or a live row stands against the Initiatives on the quarter: New, Unchanged, Changed or Unsourced. Step 5 defines each. _Avoid_: status (that is the row's `Status`), diff.

- **Rename**: a proposed title that differs from the title of the live row covering the same work. Never applied silently: the user confirms it. _Avoid_: retitle, re-key.

- **Round**: one message of numbered questions, each with a recommendation worded so that "yes" accepts it, after which the skill waits. "Just write it" accepts every remaining recommendation. _Avoid_: batch, survey.

- **Frontier**: the questions still open after a round: a recommendation the user changed, an answer that raises a new question, or a draft that still fails a test. The grill ends when it is empty. _Avoid_: backlog, parking lot.
